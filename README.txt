바로 보기
---------
1. 압축을 풉니다.
2. index.html 을 크롬, 엣지, 사파리로 더블클릭해서 엽니다.
   * 폴더 구조(assets 폴더 포함)를 그대로 유지해야 지구본이 보입니다.
   * 글꼴은 Google Fonts에서 불러오므로 인터넷 연결 시 가장 정확하게 보입니다.

인터넷에 올리기 (무료)
---------------------
- Netlify Drop: https://app.netlify.com/drop 에 SAZE-websites 폴더를 통째로 끌어다 놓으면 바로 주소가 생깁니다.
- GitHub Pages: 새 저장소에 폴더 안의 파일을 올리고 Settings → Pages 에서 켜면 됩니다.
- 기존 홈페이지에 넣을 때는 HTML 파일과 assets 폴더를 같은 위치에 올리세요.
